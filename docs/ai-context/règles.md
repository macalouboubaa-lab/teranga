# Règles de codage

- Utiliser TypeScript avec des types précis ; ne pas utiliser `any`.
- Utiliser `export default function`, PascalCase et `use client` seulement si nécessaire.
- Centraliser Supabase dans `lib/supabaseClient.ts`.
- Préférer les composants réutilisables et Tailwind.
- Ne jamais commiter de secrets.
- Ne pas ajouter de backend Node API sans décision d’architecture.
- Vérifier avec `npm run lint` et `npm run build` lorsque possible.
- Mettre à jour `tasks.md` et `memory.md` après une session importante.
- Convention de commits : **[À REMPLIR]**.
